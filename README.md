# TasteMatch

A swipeable food preference interface built with React Native (Expo).

## 🚀 Quick Start

### Installation & Running

```bash
# 1. Clone the repository
https://github.com/HoorainEjaz231/TasteMatch.git
cd TasteMatch

# 2. Install dependencies
npm install

# 3. Start the Expo server
npx expo start
